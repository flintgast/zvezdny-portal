# T-XXX · Короткое название задачи

**Режим:** A (оба ИИ независимо) / B (закреплённый участок)
**Кому:** Claude / Grok / обоим
**Заведена:** ГГГГ-ММ-ДД
**Статус:** открыта / на приёмке / принята / отклонена

---

## Что нужно сделать

Одна-две фразы. Конкретно. Не «улучшить миссию», а «написать структуру миссии 5
и предложить, как древний контур работает как игровая механика».

## Зачем это нужно

Одна фраза, чтобы исполнитель понимал, во что его работа встроится, и мог
предложить лучшее решение, чем заказанное.

## Что читать

Строгий список файлов канона. Не «всю лор-библию», а конкретные разделы —
исполнитель не должен угадывать.

- `STATE.md`
- `lore/lore_bible.md` — разделы X, Y
- ...

## Что должно быть в результате

Проверяемый список. По каждому пункту потом легко сказать «есть / нет».

- [ ] ...
- [ ] ...

## Рамки

Чего делать **не** нужно, и что менять нельзя. Самый недооценённый раздел:
без него исполнитель обязательно улучшит что-нибудь соседнее.

- Не трогать: ...
- Не выходить за: ...

## Объём

Ориентир по размеру. Без него один пришлёт страницу, второй — двадцать, и
сравнивать будет нечего.

## Формат сдачи

`inbox/from-<имя>/T-XXX_название.md`, в конце — блок «ЗАЯВКА В КАНОН»
(см. `HANDOFF.md`, раздел 5).
