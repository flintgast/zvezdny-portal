# «Звёздный портал» *(рабочее название не выбрано)*

Игра и, в перспективе, фильм по оригинальному лору: тайная экспедиция 1938 года
ищет три точки планетарного портала — и находит вместо ответа дверь во времени.

Жанр: нарративная изометрическая пошаговая тактика с отрядом и перманентными
потерями.

---

## Как устроен репозиторий

```
STATE.md            ← источник правды. Читать первым, всегда
HANDOFF.md          ← протокол совместной работы Claude + Grok + Флинт
BRIEF_FOR_AI.md     ← бриф для входящего ИИ: тон, стиль, механика, грабли

lore/
  lore_bible.md     ← лор-библия, актуальная версия (номер внутри файла)
  archive/          ← прошлые версии, для истории

design/
  gdd.md                    ← геймдизайн: жанр, движок, вертикальный срез
  act1_1938_missions.md     ← структура 10 миссий Части 1
  act1_script.md            ← прозаические сцены подготовки (УСТАРЕЛ)
  act2_1983_..._DEPRECATED.md  ← миссии 1983 (УСТАРЕЛ, снятая сюжетная линия)

prototype/
  prototype_scene.html      ← играбельный прототип боевой механики

tasks/              ← карточки задач: T-001, T-002, ...
inbox/
  from-claude/      ← результаты Claude (предложения, не канон)
  from-grok/        ← результаты Grok (предложения, не канон)
art/                ← референсы, концепты
```

**Главное правило:** всё, что вне `inbox/`, — канон. Правки в канон вносит
только Флинт. ИИ кладут предложения в свою папку `inbox/`. Подробности — в
`HANDOFF.md`.

---

## Прототип

Открыть `prototype/prototype_scene.html` в браузере — файл самодостаточный, ни
сервера, ни сборки не требует.

Тестовая сцена «Святилище» (Тибет, 1938) проверяет: броски Резонансного
индикатора, стрельбу с укрытиями и линией огня, прыжок через разлом, зону гула
излучателя, компенсатор и резонансный импульс.

## Первый запуск (для Флинта)

Создать на GitHub пустой приватный репозиторий, затем:

```bash
cd zvezdny-portal
git remote add origin https://github.com/<логин>/<репозиторий>.git
git branch -M main
git push -u origin main
```

Дальше — обычный цикл: положил файл из `inbox/`, `git add .`,
`git commit -m "claude: T-001 черновик"`, `git push`.
